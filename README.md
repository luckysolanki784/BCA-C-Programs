# BCA-C-Programs

A collection of C programs practiced during BCA 1st Year lab sessions.

This repository documents my learning journey in C programming - from basics to loops and logic building.

### 📂 Programs Included
- Basics: `hello_world.c`, `student_details_input.c`
- Conditional: `largest_of_three.c`, `positive_negative_zero.c`, `vowel_consonant.c`
- Loops: `for-loop-hello-16-times.c`, `Even Series`, `Table`
- Logic: `swap_two_numbers.c`, `rectangle_area_perimeter.c`, `temperature_conversion.c`
- Switch Case: `calculator_switch.c`, `weekday_switch.c`, `student_grade.c`
